## Section 4 — LaTeX Generator for Overleaf (abntex2)

### New files

- `scripts/build_latex.py` — new script, reads `projeto.json` + `resultados_calculo.json`, writes the `.tex` file
- `07_latex/relatorio_tecnico.tex` — generated output (never edit manually)
- `07_latex/figuras/` — generated output, contains diagram images copied from `06_dashboard/renders/`

### Document class and ABNT compliance

```latex
\documentclass[12pt,a4paper,oneside,english,brazil]{abntex2}
```

`abntex2` handles: page margins (ABNT NBR 14724), section numbering, caption format, figure captions, and reference format. All tables use `\IBGEtab` with `\legend{}` citing the source. Figures use `\legend{Fonte: elaborado pelos autores.}` where generated.
